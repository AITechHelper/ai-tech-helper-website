# Homepage images — drop your files here

Put image files in this folder (`aitechhelper-site/public/images/`). A file
placed here at `public/images/foo.png` is served on the live site at
`/images/foo.png`. Any slot without a file just shows a clean labelled
placeholder until you add one — nothing breaks.

## Slots the homepage looks for

| File to add                     | Where it shows                         | Recommended size        |
| ------------------------------- | -------------------------------------- | ----------------------- |
| `dashboard.png`                 | Services section — the big product shot | 1600 × 900 (16:9), PNG/JPG |

That's the only wired-up image slot right now. Want more (a hero product shot,
a "meet the owner" photo, a review screenshot band, per-service screenshots)?
Tell me which and I'll add the slots — then you just drop the matching files in
here with the filenames I give you.

## Tips
- Keep files reasonably small (aim < 400 KB each; export at ~80% quality).
- Use `.jpg` for photos, `.png` for UI screenshots with sharp text.
- Filenames are case-sensitive and must match exactly (all lowercase here).
